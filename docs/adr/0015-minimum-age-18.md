# ADR 0015: Minimum age 18+

- Status: Accepted
- Date: 2026-11-16
- Source: Blueprint v4.0 section 0.2 and the Phase 0 audit

## Context
Older docs allowed 13+.

## Decision
Require 18+ until a legally reviewed, verifiable parental-consent flow exists (the India DPDP Act treats under-18s as children).

## Consequences
Confirm with legal counsel before launch.
